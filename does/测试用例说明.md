# 测试用例说明
> 笔试提交要求：覆盖主链路、数据/接口异常、合规边界；关键数字与结论必须可追溯evidence_id。

## 1.正常主链路用例
T‑001 查询电化学储能产业链
预期：输出完整5层产业链；区分L4/L3/L2/L1标的；L1蹭概念标的（山东章鼓、国机通用）标记概念炒作；**每条标的产业链归属输出chain_link_evid_ids证据溯源ID**；展示信源等级、证据类型；D级股吧证据不会拉高业务可信度。

T‑002 中外公司对比（阳光电源 vs Fluence）
预期：LLM抽取两家业务特征；输出可比维度、不可比维度；**维度结论绑定comparable_evid_ids/incomparable_evid_ids溯源ID**。

T‑003 外部冲击传导推演 event‑002美国IRA补贴收紧
预期：返回事件信源等级、event_source_desc、affected_chain_links、impact_direction、related_fin_index、transmission_confidence、transmission_precondition前置生效条件。

## 2.数据/接口异常用例
T‑004 MCP simulate_timeout=true
预期：返回504友好提示；异常完整写入ai_records日志。

T‑005 MCP simulate_empty=true
预期：返回空列表+友好业务提示。

T‑006 LLM调用异常
预期：抛出500友好报错；失败请求强制落盘ai_records日志。

## 3.信源&红旗专项测试
T‑007 D级低可信证据测试：山东章鼓A公告+D股吧百亿订单传闻
预期：D级证据命中关键词不提升标的可信度；页面提示D级低可信线索。

T‑008 R01单信源红旗；T‑009 R02同源复制；T‑010 R03高可信信源冲突
预期：触发对应红旗描述与处置动作；R03触发可信度自动降级。

## 4.合规边界测试
T‑011 全部业务接口访问
预期：接口顶层返回机器可读disclaimer；页面展示免责声明；不输出任何个股买卖、估值、收益率建议。

## 可追溯校验要点
1. 产业链归属结论：必须返回chain_link_evid_ids；
2. 中外可比/不可比结论：必须返回comparable_evid_ids / incomparable_evid_ids；
3. 审计日志ai_records_*.jsonl每条记录携带source_evidence_id证据元数据；
4. 审计敏感字段raw_llm_response、human_review不会出现在业务接口JSON返回。
